# BachRAG

Локальное Flask-приложение для вопросов по собственным документам. Загружает файлы, разбивает их на фрагменты, строит векторный индекс FAISS и формирует ответ с помощью LLM, используя найденные источники.

## Возможности

- Загрузка PDF, TXT, Markdown, DOCX и CSV через веб-интерфейс.
- Обработка PDF через Docling: текст, таблицы, финансовые показатели и ссылки на страницы.
- Поиск с моделью `ai-sage/Giga-Embeddings-instruct` и повторное ранжирование через `BAAI/bge-reranker-v2-m3`.
- Разбиение вопроса на подзапросы, поиск подтверждений и единый ответ с источниками.
- Отображение состояния индексации, управление файлами и история текущего чата.
- Загрузка моделей по необходимости: открытие интерфейса не скачивает модели.

## Установка

Нужен Python 3.11 или 3.12. Для новой установки рекомендуется 3.12. Модели работают на CPU; при доступной CUDA используется GPU. Для первого скачивания моделей нужен интернет, а обработка больших PDF требует достаточного объёма памяти.

```bash
git clone --branch main https://github.com/whiteage/bachrag.git
cd bachrag
python -m venv .venv
```

Активируйте окружение в PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Или в Linux/macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## API ключ и конфигурация

Скопируйте `.env.example` в `.env` и укажите новый ключ:

```dotenv
DEEPSEEK_API_KEY=your_new_key_here
```

`.env` исключён из Git. Приложение читает его рядом с исходниками; переменные окружения имеют приоритет. Не публикуйте ключи. Если ключ раньше попадал в Git, отзовите его у провайдера: удаление из текущей версии не удаляет старые коммиты.

| Переменная | Назначение | По умолчанию |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | Ключ DeepSeek | Не задан |
| `BACHRAG_DATA_DIR` | Каталог документов и индекса | `runtime/` рядом с исходниками |
| `LLM_PROVIDER` | Провайдер: `deepseek` или `openai` | `deepseek` |
| `LLM_MODEL` | Модель для ответов | `deepseek-chat` для DeepSeek |
| `LLM_BASE_URL` | Адрес совместимого API | `https://api.deepseek.com` для DeepSeek |
| `LLM_API_KEY` | Общий ключ, приоритетнее ключа провайдера | Не задан |
| `OPENAI_API_KEY` | Ключ при `LLM_PROVIDER=openai` | Не задан |

Для другого совместимого сервиса задайте `LLM_MODEL`, `LLM_BASE_URL` и `LLM_API_KEY`. Ключ также можно ввести в интерфейсе: он действует до перезапуска процесса и не сохраняется на диск. Индексирование работает без ключа; для ответов нужен доступ к LLM.

## Запуск и использование

```bash
python app.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000).

1. Загрузите документы в боковой панели.
2. Нажмите кнопку индексации и дождитесь завершения. При первом запуске загрузятся модели.
3. Введите API ключ, если он не настроен через `.env`.
4. Задайте вопрос, например: «Как изменился капитал между 2024 и 2025 годом?».
5. Проверьте ответ и указанные источники.

После добавления, замены или удаления файла старый индекс сбрасывается. Повторная индексация пересобирает текущий набор документов, чтобы поиск не возвращал удалённые или устаревшие фрагменты. Во время индексации изменение файлов блокируется. Максимальный размер одного HTTP-запроса с файлами — 200 МБ.

Приложение рассчитано на локальную работу одного пользователя в одном процессе. История чата хранится в памяти и очищается при перезапуске. PDF обрабатываются без OCR: сканы без текстового слоя требуют предварительного распознавания. Текстовые файлы читаются в UTF-8; для DOCX извлекаются абзацы и текст таблиц.

## Хранение данных

```text
runtime/
├── uploads/                     # Загруженные документы
├── brand.index                  # Векторы FAISS
├── chunks.json                  # Тексты и метаданные фрагментов
└── uploaded_files_state.json    # Состояние документов
```

Каталог `runtime/`, секреты, настройки IDE и результаты обработки исключены из Git. Содержимое документов хранится локально; при вопросе текст вопроса и отобранные фрагменты отправляются настроенному провайдеру LLM.

Старые `data.pkl`, индексы и экспериментальные данные больше не используются. Для перехода со старой версии загрузите нужные документы заново и пересоздайте индекс. Код не загружает прежние pickle-файлы.

## Структура проекта

```text
app.py                    # Flask API, состояние приложения и запуск индексации
cfg.py                    # Общие пути, переменные окружения и настройки LLM
document_processing.py    # PDF, текстовые фрагменты и обработка таблиц
embedder.py               # Модели, FAISS, JSON-хранилище и ранжирование
rag.py                    # Подзапросы и формирование ответа по источникам
templates/index.html      # Веб-интерфейс
static/                   # JavaScript и CSS
tests/                    # Регрессионные тесты без внешних API и моделей
```

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -m ruff check .
python -m unittest discover -s tests -v
node --check static/app.js
```

Тесты проверяют загрузку файлов и API, актуальность индекса, обработку таблиц, поиск и ответы на некорректный JSON от LLM. Сквозной тест сохраняет и загружает настоящий индекс FAISS, затем проверяет замену и удаление документов. Внешние модели и платные API заменены тестовыми объектами. Для быстрой проверки без установки моделей достаточно `Flask`, `python-dotenv`, `numpy`, `faiss-cpu` и `ruff`. GitHub Actions запускает линтер и эти тесты при push и pull request.
